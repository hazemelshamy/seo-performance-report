Issue 01 — Critical Priority

🔴 Critical Mobile Redirect: animaat.com → Google Play Store

Accessing https://www.animaat.com/ on mobile triggers a redirect to the Play Store. Google's mobile crawler indexes the Play Store page instead of animaat.com.

✓ Solution

1. Remove or fix the mobile redirect immediately. Check the .htaccess file or WordPress plugins for User-Agent-based redirects.

2. Implement a Smart App Banner instead.

Issue 02 — Critical Priority

🔴 Mobile Performance Score 40/100

PageSpeed mobile FCP at 12.5s, LCP at 23.5s, due to unused JS (1,121 KiB) and render-blocking requests.

✓ Solution

1. Implement Code Splitting & Lazy Loading.

2. Enable HTTP/2 and modern image formats (WebP).
